# SPEC-0010: Mitigación de Deuda Técnica, Fugas de Memoria y Cotización Dinámica del Dólar

## Estado
- **Status:** In Progress
- **Asignado a:** Agente Inteligente Antigravity
- **Fecha:** 2026-06-19

## Criterios de Aceptación
1. **Dólar Blue en Tiempo Real:**
   - Consultar la cotización del dólar blue desde `https://dolarapi.com/v1/dolares/blue` cada hora.
   - Almacenar la cotización en `cache/dolar_blue.json`.
   - Si el precio fluctúa con respecto al caché en disco, actualizar la caché e imprimir en logs estructurados.
   - Utilizar el precio dinámico de la caché en el algoritmo de matching. Si la API falla, utilizar `1200` como fallback.
2. **Caché de Supabase Clients:**
   - Evitar re-instanciar clientes de Supabase para el mismo token de tenant en cada HTTP request.
3. **Gestión de Recursos en WhatsApp Connection:**
   - Prevenir llamadas de reconexión tras logout rastreando los timeouts en un mapa dinámico.
4. **Colas Asíncronas Concurrentes por Tenant:**
   - Las búsquedas e intenciones de un tenant no deben encolarse ni esperar tras las colas de otros tenants.

## Detalles de Implementación

### Dolar Blue
Se define un módulo `src/services/dolar.ts` que se encarga del fetch de `https://dolarapi.com/v1/dolares/blue` y expone `getDolarBlueRate(): number`.

### Supabase Client Reuse
El módulo `src/services/supabase.ts` implementará un mapa global `const tenantClientsCache = new Map<string, SupabaseClient>();` en base al token JWT para retornar instancias cacheadas.
