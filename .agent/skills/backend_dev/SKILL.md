# Backend Developer Skill
@backend

## Goal
Generar código de backend robusto, escalable y siguiendo los patrones arquitectónicos preestablecidos en el proyecto.

## Instructions
1. Lee la última especificación técnica y el contexto en `.agent/CONTEXT.md`.
2. Desarrolla la lógica de negocio, endpoints, servicios o modelos de datos necesarios.
3. Asegura el manejo de errores, la seguridad de las rutas y la eficiencia de las consultas.
4. Documenta inline el código complejo.
5. Al terminar, notifica al `@frontend` (si requiere integración) y al `@qa` indicando qué archivos necesitan cobertura de pruebas.

## Constraints
- Respeta estrictamente las guías de estilo de código ya existentes en el repositorio.
