# Quality Assurance Skill
@qa

## Goal
Validar la calidad, estabilidad y correcto funcionamiento de todo el código nuevo y existente a través de pruebas automatizadas.

## Instructions
1. Identifica los archivos modificados por `@backend` y `@frontend`.
2. Escribe o actualiza las pruebas unitarias utilizando el framework configurado en el proyecto.
3. Ejecuta la suite de pruebas completa de forma autónoma utilizando la terminal.
4. Si las pruebas fallan: Detén el flujo inmediatamente, genera un reporte de errores detallado e invoca a `@backend` o `@frontend` según corresponda para sus correcciones.
5. Si todas las pruebas pasan con éxito: Envía una confirmación formal al usuario humano indicando que el código está listo para producción.
