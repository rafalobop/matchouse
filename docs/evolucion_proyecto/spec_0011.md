# SPEC-0011: Arquitectura de Propiedades Centrada en Base de Datos

## Estado
- **Status:** In Progress
- **Asignado a:** Agente Inteligente Antigravity
- **Fecha:** 2026-06-19

## Criterios de Aceptación
1. **Eliminación de Google Sheets:**
   - Remover el módulo `src/services/sheets.ts` y sus dependencias (inactivos).
2. **Propiedades Base de Datos First:**
   - La carga inicial de catálogo se realiza únicamente leyendo de Supabase. Si no hay registros, el catálogo del tenant en memoria arranca en vacío `[]`.
   - Se eliminan las copias JSON en disco local (`cache/catalog_*.json`).
3. **Subida de Excel Directa:**
   - Al subir un Excel, se parsea el buffer, se sincroniza en Supabase y se actualiza el catálogo en memoria del orquestador en un único paso atómico, omitiendo archivos en disco.

## Detalles de Implementación
- El tipo `Property` e heurísticas de `detectTipoPropiedad` se migran a `src/services/excel.ts`.
- Se remueve `sheets.ts` y sus llamadas del código.
